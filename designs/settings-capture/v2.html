Settings › Capture, v2: one Screen capture page

Screen capture, Text and QR and Color picker share one page, since all three start from the same frozen screen. One Shortcuts card holds all 13, grouped by feature, and the Capture group in the sidebar has one entry. Displays keeps its own page under System.

The Settings window at its real 1120 width, measured from a real snapshot of main: rows, keycaps, Edit links and switches as shipped. Each feature page shows its keys read-only with Edit, which opens the row in Settings › Shortcuts. Only Capture region has a default key (Print Screen). Every page is dark; Screen capture is also shown light.

Pick this one if you'd rather set up capture in one place; it breaks the one-page-per-feature rule, and the page is long.
