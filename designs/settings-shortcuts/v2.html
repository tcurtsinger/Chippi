Settings › Shortcuts, v2: grouped as the sidebar is

Rows sit under the same areas as the sidebar (System, Windows, Capture), so a shortcut is found where its feature is. Fewer headings; a row from a feature with several shortcuts names its feature on a second line.

The Settings window at its real 1120 width. Rows, keycaps, Record and the … menu (Change, Remove) are measured from a real --settings-snapshot of main. Only Print Screen (Capture region) and Command bar's existing Ctrl+Alt+Space are set by default; Open Notes and Play or pause stand in for shortcuts Travis adds with Add shortcut. The Caps Lock and Mouse buttons sections don't change.

Pick this one if you think of features by area; the second lines make Capture's 13 rows taller.
