Settings › Media tools, v2: keys first, one short card

Laid out like most shipped feature pages: the three shortcuts lead, then the four options in one card with tighter rows, in the brief's order.

The Settings window at its real 1120 width, with the shipped rows, switches, keycaps and Edit links. Each shortcut is read-only here; Edit opens its row in Settings › Shortcuts. All three start unassigned. Originals are never changed: files go beside them unless you choose a folder.

Pick this one if you'd rather start Convert, Resize and Compress from keys than change these options.
