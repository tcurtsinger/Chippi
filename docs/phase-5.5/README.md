# Phase 5.5: Everyday tools, continued

Quick actions (planned as Quick toggles), Cleaning mode, Command bar, Radial menu and AI agent usage (PLAN.md). Shaped with Travis from 2026-11-01, one feature at a time, by asking rather than assuming.

## Decided (Travis, 2026-11-01)

- **Scope:** all five stay in Phase 5.5.
- **Order:** Quick actions and Cleaning mode first: the smallest two, both at home on the island, and their actions can fill the Command bar and Radial menu later. Then the other three.
- **Overlap:** Travis uses no launcher (PowerToys Command Palette or Run, Flow Launcher, Everything), and doesn't use Windows Quick Settings' toggles, so nothing overlaps for him.
- **Review:** a written brief per feature, confirmed, then an interactive mockup of each new surface, approved before it's built (as Phases 4, 5 and 5.1 were).
- **The island's labels are one word** (from the Quick actions review): every name under a home button and every label on the Actions page. The home goes to 5 columns, so Actions and Search (the Command bar) fit beside the 8 it has. Details in [quick-actions.md](quick-actions.md) and [command-bar.md](command-bar.md).

## Radial menu, shaping so far (Travis, 2026-11-01)

Round 1 answered; no brief yet.

- **Trigger:** customizable in Settings (keyboard shortcut, mouse side buttons, middle-button hold were offered; the user picks).
- **Position:** opens at the pointer.
- **Actions:** apps, files and links; key shortcuts; Chippi's actions; media controls; plus other useful kinds Claude should propose.
- **Organizing:** submenus (a slice opens a second wheel). Not profiles, not per-app wheels.
- **Next:** propose the extra action kinds, then round 2 (hold-and-release vs press-to-open, slice count, what happens with a fullscreen game in front, the Settings editor), then the brief and its mockup.
