Sound page, made uniform

One control card shape (56 tall: glyph, live state, one button or switch at the right) and one row shape (44 tall). Both columns start their device rows at the same height. The output's name leaves its card, since the selected row already says "Playing now". Mic processing (was Clean-up) becomes a control card like the other two. Right: the same page muted, with Mic processing on; nothing changes size.

System monitor, basic

360 wide, two tables on one 32px row: the readings (detail, then the value at the right edge) and Disks (Used, Free, Total). A value turns Caution when its alert fires. Gone: the graphs, "Last 4 min", the processor strip, Committed, Shared, GPU fan, and the disk activity and speed columns. Battery and Thermal zone add rows when the PC has them. A chevron after GPU or Network appears only with more than one to pick from.
