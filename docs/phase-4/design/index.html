System monitor: Phase 4 mockup

Inside the Surfaces model (PR #52). The island and docked pages are always dark; Settings is shown dark and light. Readings are sample values. Notes: notes.md.

1 · All features, top edge

The System monitor tile joins the grid after File organizer. Its status is the reading Settings picks (CPU by default).

2 · System monitor page, top edge

Travis's desktop: two GPUs (picker), one real network adapter (no picker), five disks, no battery, no thermal zone. 640 wide, like Sound.

3 · System monitor page, right edge

The same page against the right edge. Round buttons: one pair above, one below, Now Playing on the far side.

4 · Docked by the tray, island off

The same page in the docked card, with the footer in place of the round buttons.

5 · Optional rows and states

Rows that only some PCs have, the logical processors open, trouble states, and an alert.

6 · Settings › System › System monitor, dark

Travis's desktop, with CPU load and GPU temperature alerts turned on (all alerts start off). The window is stretched to show the whole page.

7 · Settings › System › System monitor, light

A laptop: Battery, Thermal zone and Low battery appear; one GPU with no temperature limit set, so its alert can't be turned on yet.

8 · A short screen (notes.md #22)

The smallest common laptop screen: 1920×1080 at 150% scaling, which apps see as 1280×720. The compact page and its round buttons fit on the right edge with room to spare.

Mockup only. Every reading is a sample.
